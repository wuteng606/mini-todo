05这版想请你定的三件事

A
猫咪要留吗？目前只在「今日待办」标题旁出现；也可以做成随完成数变化的情绪状态（完成越多越开心），或换成你自己的形象/插画。
B
左侧图标栏保留还是去掉？去掉更像参考图那种纯净卡片，保留更符合 Mac 多清单的用法。我倾向保留但默认收起，鼠标移入才展开。
C
玻璃用系统真模糊还是 CSS 近似？真模糊（系统 vibrancy）更高级但耗电略高；纯 CSS 在同价位机器上更稳。建议主窗口用真模糊，弹窗用 CSS。
