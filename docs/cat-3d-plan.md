# 3D 猫咪吉祥物 · 技术设计方案

## 一、目标

把现在这张 PNG 猫咪换成**实时渲染的 3D 小猫**，让「逗猫」成为应用的一个小彩蛋：

- 鼠标移动 → 小猫转头、眼睛跟着你走
- 鼠标悬停 → 耳朵竖起、尾巴加快、身体轻轻起伏
- 点击 → 起跳、落地挤压回弹、飘出爱心、随机一句喵
- 空闲 → 呼吸、眨眼、偶尔抖耳朵
- 完成任务 → 转圈欢呼

## 二、技术选型

| 方案 | 评价 |
| --- | --- |
| **Three.js + 程序化建模（推荐）** | 无需外部模型资产，包体约 +150KB(gzip)，可控性最好，能直接复用现有配色 |
| react-three-fiber | 声明式写起来舒服，但对这个单场景来说多一层抽象、多 30KB，暂不引入 |
| 引入 glTF 猫模型 | 真实感上限最高（可带骨骼/毛发贴图），但需要找到授权合适的资产，且体积 2–8MB |
| 2D + CSS 3D | 做不到真正的光照与视角变化，pass |

**结论：Three.js r170 + WebGL2，几何体程序化拼装 + PBR 材质 + 三点布光。**

毛发的"真实感"靠三件事堆出来，而不是靠毛发模拟：

1. **MeshPhysicalMaterial** 的 `sheen`（绒面反射），让边缘有绒毛感
2. **三点布光 + 边缘光**：暖色主光、冷色轮廓光，把轮廓从背景里剥出来
3. **软阴影 + ACES 色调映射**，避免塑料感

## 三、场景结构

```
Scene
├─ HemisphereLight（天光，暖白 → 冷紫）
├─ keyLight   平行光，暖色，投影 1024 shadow map
├─ rimLight   平行光，冷蓝，勾边
├─ fillLight  点光，暖粉，补脸
├─ cat (Group)
│  ├─ body / chest / head / ears / muzzle / eyes / blush / paws
│  └─ tailGroup（TubeGeometry 曲线尾巴）
└─ shadowCatcher（ShadowMaterial 透明地面，只接收阴影）
```

相机 `PerspectiveCamera(30°)`，俯角约 8°，正交感更强、比例更可爱。

## 四、交互状态机

| 状态 | 触发 | 表现 |
| --- | --- | --- |
| `idle` | 默认 | 呼吸缩放 1±0.02（3s 周期）、随机眨眼、尾巴慢摆 |
| `tracking` | 指针移动 | 头部/眼睛朝指针 lerp（阻尼 0.12），身体轻微侧倾 |
| `hover` | 指针进入命中球 | 耳朵前压、尾巴频率 ×1.8、光晕增强 |
| `press` | 按下 | 整体下压 0.04、耳朵后折 |
| `jump` | 点击（位移 <6px） | 0.65s：蹲 → 起跳 0.55 → 落地挤压回弹，同时爆 12 颗爱心 |
| `celebrate` | 完成任务 | 转一圈 + 连跳，1.1s |

所有动画都用**基于时间的插值**，不用 CSS/GSAP，避免依赖；每帧 `delta` 限幅 1/30 防跳帧。

## 五、性能与降级

- 三角形 < 15k，一个 canvas，纹理只有一张 64×64 爱心
- `renderer.setPixelRatio(min(dpr, 2))`，尺寸变化用 ResizeObserver
- 窗口失焦 / 页面隐藏 → 暂停 rAF
- WebGL 不可用、`prefers-reduced-motion` → 直接回退到现有 PNG，不做任何 3D 初始化
- 设置里给一个「3D 猫咪」开关，默认开

## 六、落地步骤

1. `design/cat-3d.html`：独立原型（Three.js CDN，双击可看），先调形状与手感
2. 抽成 `createCat(container)` 纯函数模块，不依赖框架
3. React 侧 `Cat3D.tsx` 挂载 / 卸载，暴露 `celebrate()` 给完成任务时调用
4. 替换 hero 里的 `<img>`，保留降级路径
5. 真机跑一轮：帧率、CPU、内存、长时间挂机是否掉帧

## 七、风险

- **可爱度靠调参**：程序化建模没有"捏脸"工具，比例要反复截图对比，初版可能不够萌
- **真实感受限**：没有毛发几何，近看仍是"软胶公仔"质感；要更真需要 glTF + fur shell
- **包体**：three 约 +600KB 原始 / +150KB gzip，对 6MB 的应用可接受
- **小尺寸衰减**：hero 区域只有 150px 时，3D 细节会浪费，建议同时放大到 170–190px 或改成可点击展开的大猫

## 八、后续可选

- 换 glTF 猫模型（带 idle/tail/ear 骨骼），用 AnimationMixer 驱动
- 加 `KHR_materials_sheen` + 轻微法线扰动模拟绒毛
- 根据完成率改变小猫状态（开心 / 打哈欠 / 睡觉）
